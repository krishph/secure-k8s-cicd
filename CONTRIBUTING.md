# Contributing

Keep changes focused and describe the user-visible behavior. Run `make check`,
`make test`, and `make scan` as applicable; record commands you did not run.
Policy changes should include a compliant case and a regression case that would
fail without the change. Keep raw manifests and Helm defaults aligned.

Do not add real cloud credentials, private kubeconfigs, or unlicensed documents.
Keep experimental performance claims separate from measured results. Dependencies
and tool versions should be updated through reviewed changes with fresh validation.
